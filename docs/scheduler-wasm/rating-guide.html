🧠 FSRS State Transitions & Rating Guide

A complete student-friendly guide on how FSRS manages memory decay, card stages, and ratings.

🌱 1. Overview of FSRS Card Stages

FSRS categorizes your coding flashcards into 4 fundamental stages as you learn and review them:

Stage 0: New

🆕 Fresh Card

A problem card you just created. You haven't practiced or tested yourself on it yet.

Stage 1: Learning

📖 Practice Mode

Short-term practice rounds (1m, 10m). You are building initial pattern memory.

Stage 2: Review

🏆 Mastered!

Card is in long-term memory. FSRS spaces out review dates exponentially (4d, 12d, 1mo).

Stage 3: Relearning

🔄 Quick Refresher

Forgot a mastered card? FSRS puts it in a quick refresher mode until it's safely back in long-term memory.

🎯 3. How to Grade Yourself (Button Guide)

🔴 Again

"I blanked out / Got stuck"
Couldn't recall the main pattern or forgot a key algorithm step.

🟡 Hard

"I got it, but it was a struggle!"
Correct recall, but required heavy effort or minor syntax hesitations.

🟢 Good (Default Choice!)

"Smooth recall!"
Remembered the approach and solved it in standard time. Make this your main button ~70-80% of the time.

🔵 Easy

"Piece of cake!"
Felt completely obvious or trivial. Pushes the next review far into the future.

🧩 4. What If I Only Remember SOME of the Problem?

The Interview Reality Check: Missing Core Logic? → Press 🔴 Again

Ask yourself: "If an interviewer gave me this problem right now, would my missing piece make me get stuck?"
If YES (e.g. forgot duplicate handling in 3Sum or DP base cases), press 🔴 Again. It's totally okay to fail a card—that's how your brain builds bulletproof recall!

Main Algorithm Solid, Just Paused on Syntax? → Press 🟡 Hard

If your high-level approach and logic were 100% correct, but you just briefly paused on language syntax (like queue or map functions), press 🟡 Hard.

💡 Student Tip: The "Break-It-Down" Rule

If a problem note feels huge and you always forget half of it, break it into 2 smaller cards! For example: Card #1 = High-Level Pattern & Time Complexity, Card #2 = Tricky Edge Cases & Base Cases.
