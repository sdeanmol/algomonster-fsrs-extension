# Dependencies & Third-Party Library Audit

## 1. Production Dependencies (`dependencies`)

Defined in [`package.json`](file:///Users/anmolrastogi/Documents/GitHub/algomonster-fsrs-extension/package.json):

```json
"dependencies": {
  "dompurify": "^3.4.17",
  "firebase": "^10.12.0"
}
```

### 1.1 `dompurify` (^3.4.17)
- **Role**: DOM sanitization library.
- **Usage**: Used in [`features/common/markdown.ts`](file:///Users/anmolrastogi/Documents/GitHub/algomonster-fsrs-extension/features/common/markdown.ts) to sanitize raw HTML generated by `marked.js` before inserting it into extension pages and in-page overlays via `innerHTML`.
- **License**: Apache-2.0 or MPL-2.0.
- **Audit Assessment**: Essential security dependency preventing stored XSS attacks from problem solution notes.

### 1.2 `firebase` (^10.12.0)
- **Role**: Cloud backend SDK.
- **Usage**: Initialized as a stub in [`features/common/firebase.ts`](file:///Users/anmolrastogi/Documents/GitHub/algomonster-fsrs-extension/features/common/firebase.ts), but **never imported or used anywhere in application business logic**.
- **License**: Apache-2.0.
- **Audit Assessment**: **Unused Dependency / Technical Debt**. Pulls in 125 MB of modules into `node_modules` without providing runtime value. Recommended for removal until cloud sync is actively implemented.
